# 🐛 BUG FIXER MAN

**Explores the internet far and wide to help the world fix bugs.**

An around-the-clock, open bug hunt run by **Kyle Cox** — GitHub [@Kshot3000](https://github.com/Kshot3000) · X [@kshot9000](https://x.com/kshot9000)

We hunt real bugs across the whole public internet — companies, crypto projects, wallets, developer tools, and open source — verify them with proof, fix them, and submit through each project's legitimate channel.

## How we work

1. **Hunt** — public code, open bug reports, and in-scope bounty programs only.
2. **Verify** — reproduce the bug locally and capture proof (failing test, log, minimal repro). No proof, no submission.
3. **Fix** — a clean, tested fix in a fork, following the project's CONTRIBUTING rules.
4. **Submit** — through the project's own channel: fork PR, bounty platform, or responsible disclosure.
5. **Log** — every hunt, fix, and submission is recorded here in `findings/`, with patches in `fixes/`.

No spam. No mass PRs. No invented bugs. One excellent, verified fix beats ten noisy ones.

## Rules we never break

- Public code and published bounty scope **only** — no unauthorized testing against live systems.
- Vulnerability details stay private until a project resolves/reports them or consents to disclosure. This repo logs links, PRs, and *resolved* reports — never live vulnerability details.
- A submitted or merged fix is **not** a paid fix. Requests and receipts are tracked separately and labeled honestly.
